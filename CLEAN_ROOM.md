# Clean-Room Statement

Signet is an original clean-room visual identity system.

The launch repository does not include third-party names, copied prompts, screenshots, images, marketing copy, proprietary skills, or copied compositions. Style recipes must be original in name, material logic, prompt text, and reference policy.

Allowed references describe general craft, material behavior, geometry, legibility, color science, platform export requirements, and human-review criteria. They must not reproduce a specific third-party visual identity.

Generated gallery and example icons should be produced from Signet's own prompts and reviewed for trademark, lookalike, embedded-text, and fake-logo risk before release.

Generated icons are still governed by the image model or production pipeline used to create them. Verify output ownership, trademark clearance, and usage rights before shipping any generated icon.

Contributor rules live in `CONTRIBUTING.md`.
